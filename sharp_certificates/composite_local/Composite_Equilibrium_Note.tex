\textbf{How to check the main result.}
The replication archive includes the original data-calibrated finite-difference
solver, both rounded candidate paths, exact centers, dual test coefficients,
verifiers, JSON outputs and run logs. The README separates a short grid check
from the full reproduction. A second interval implementation computes the
primary center defect from posterior quotients. A numerical derivative check
uses the archived solver's separate backward and forward routines. The included
audit guide identifies where an independent reviewer can check each inequality.\par
